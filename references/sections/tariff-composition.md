# Тариф (`tariff-composition`)

---

## Общая информация

С помощью метода API из этого раздела вы можете получить информацию о текущем
тарифе пользователя в категории «Недвижимость»: статус тарифа, вертикаль,
уровень тарифа, а также остатки, лимиты и размеры пакетов размещений (LF).

Важно: метод доступен только пользователям с платным тарифом (Расширенный
или Максимальный) в категории «Недвижимость».
