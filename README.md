# avito-api

Agent Skill в формате [agentskills.io](https://agentskills.io) для работы с [Avito Business API](https://www.avito.ru/developers/api-catalog) — управление объявлениями, чатами Messenger, Авито.Доставка, Авито.Работа, Автозагрузка, Автотека, Авито Promo, статистика, тарифы, CPA, продвижение, Авито Реклама, цифровые товары и остальные разделы официального каталога.

В коробке: снимок официального OpenAPI 3.0 спека (248 путей / 256 операций / 27 разделов, выгружен **03.10.2026**), родная per-section документация Avito с историей изменений, OAuth2-хелпер для токена, CLI для поиска по спеку без необходимости тащить ~2.2 МБ JSON в контекст и сборщик снимка. Подробности и порядок обновления: [источники](references/sources.md).

## Структура

```
avito-api/
├── SKILL.md                        инструкции для агента
├── scripts/
│   ├── get_token.py                OAuth2 Client Credentials → access_token
│   ├── build_spec.py               выгрузка каталога → спек, индекс, sections/
│   └── lookup_endpoint.py          tags / search / show по OpenAPI
└── references/
    ├── avito-api-openapi.json      полный мерженый спек
    ├── sources.md                  источники, дата проверки и порядок обновления
    ├── ads-sdk.md                  официальные SDK Авито Реклама
    ├── index.md                    плоский per-section индекс эндпоинтов
    └── sections/<slug>.md          официальные интеграционные доки Avito
```

## Установка

Скопируй папку `avito-api/` в каталог скиллов своего агента. Для Claude Code:

```bash
cp -r avito-api ~/.claude/skills/avito-api
```

Для других совместимых клиентов (Cursor, Goose, Copilot, OpenCode, OpenHands, Letta, и др. — [полный список](https://agentskills.io/clients)) — см. их инструкцию по подключению Agent Skills, обычно тоже папка с `SKILL.md`.

## Использование

После установки скилл триггерится сам, когда агент видит запросы вида «Avito API», «авито апи», «объявления на авито», «чаты авито», «Автозагрузка», «Автотека» и т.д. От пользователя нужны только credentials.

### Получить credentials

Для Business API получи `client_id` и `client_secret` через настройки API аккаунта / [портал разработчика](https://www.avito.ru/developers). Доступ зависит от продукта и прав аккаунта. Для Авито Реклама администратор выпускает отдельные ключи во вкладке API рекламного кабинета; они привязаны к рекламному аккаунту. Настрой секреты локально через переменные окружения:

```bash
export AVITO_CLIENT_ID=...
export AVITO_CLIENT_SECRET=...
```

### Что агент сделает дальше

1. Прочитает [SKILL.md](SKILL.md), узнает про auth, base URL и навигацию.
2. Через `lookup_endpoint.py search/show` найдёт нужный эндпоинт и его схему — без чтения ~2.2 МБ JSON.
3. На сложных интеграциях откроет `references/sections/<slug>.md` (например, `delivery-sandbox.md` — 200 КБ родного гайда от Avito).
4. Выполнит разрешённый запрос через HTTP-клиент или SDK и вернёт результат. Без ключей подготовит интеграцию и укажет, что реальные вызовы не проверены.

## Официальные SDK Авито Реклама

Для интеграции с рекламным кабинетом доступны SDK Avito на Python, Go, TypeScript и PHP. Они поддерживают токены, пагинацию и повторы запросов. Выбор клиента, различия между Ads и Promo, настройки sandbox и ограничения повторов описаны в [руководстве по SDK](references/ads-sdk.md). Эти библиотеки покрывают только Ads API.

## Источник и атрибуция

OpenAPI-спек и per-section markdown в `references/` собраны напрямую из официального каталога **`www.avito.ru/developers/api-catalog`** (через внутренний API портала `GET /web/1/openapi/list` и `GET /web/1/openapi/info/<slug>`). Содержимое — собственность ООО «КЕХ еКоммерц», воспроизводится здесь в технических целях для интероперабельности агентских клиентов с Avito Business API.

Условия использования API: <https://www.avito.ru/legal/pro_tools/public-api> ([PDF](https://developers.avito.ru/docs/APITermsOfServiceV1.pdf)). Текущая редакция условий при этой проверке не проверена; наличие файлов в репозитории не заменяет проверку прав на их использование и распространение.
